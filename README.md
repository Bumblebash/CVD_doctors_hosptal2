# 🩺 CVD Doctors Hospital - Heart Disease Predictor

This is a Django-based full-stack web app that predicts the likelihood of cardiovascular disease using a trained ML model.

🔗 Live Demo: https://cvd-doctors-hosptal2-18.onrender.com  
📁 GitHub Repo: https://github.com/Bumblebash/CVD_doctors_hosptal2.git

## 🚀 Features
- User form to input clinical data
- Trained ML model for real-time prediction
- Django backend with HTML frontend
- Render deployment using Gunicorn

## 🔧 Tech Stack
- Python, Django, Scikit-learn
- Pandas, Numpy
- HTML/CSS, Bootstrap
- Render.com for deployment
